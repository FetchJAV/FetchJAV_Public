Documentation

A complete guide to installing and using FetchJAV.

Overview

FetchJAV is a privacy-first desktop application for Windows that lets you browse supported video sites, download videos in the background, generate subtitles locally, and organize everything in one library.

Every feature runs on your machine. Downloading, transcription, metadata, and playback all happen locally — FetchJAV is not a service, it is software you install and own. No account or API key is required.

FetchJAV ships with support for JableTV, MissAV, and SupJav. The developers are constantly integrating more supported websites into stable releases, so keep an eye on new updates.

FetchJAV is closed-source software. The source code is proprietary and not publicly available. Redistribution or reverse engineering of the application is not permitted without written consent.

Getting started

1. Download the app

Go to the Download page and grab the latest Windows executable (.exe). FetchJAV is a portable one-click run app.

2. Run the app

For security purposes, FetchJAV is never installed on your device. Just run the .exe and it starts immediately — it does not install anything on your PC and leaves nothing behind once you stop it. Close the app when you are done, and nothing remains.

3. Keep the default download folder

We recommend not changing the download directory. The AI system needs the downloaded files in the default location to recognise the audio and generate subtitles correctly. Once you have selected a different folder or relocated the files to another location, the AI system can no longer find the audio, and subtitle generation will not work correctly.

System requirements

Operating system

Windows 10 or 11, 64-bit recommended. Windows 8.1 and older will not give the best performance.

Memory & storage

4 GB of RAM is recommended. Storage depends on your library — HD video averages 1–2 GB per hour, plus subtitle and metadata files, which are small.

Optional components

FFmpeg — enables advanced container handling and additional format support. If FFmpeg is not present, FetchJAV falls back to its built-in handling for common formats.

Local Whisper runtime — enables faster, fully-offline transcription. Without it, subtitle generation is slower or requires a network-backed model depending on your configuration.

LLM provider — an optional API key for higher-quality subtitle translations. Everything else works without one.

Usage

Browse & search

Browse supported sources directly inside the app, search videos by keyword, and filter results by category. Cards show previews and metadata at a glance. Select multiple cards, then add them to the download queue or start downloading instantly.

Downloads

Downloads run in the background with automatic retries and resumable transfers. Every download keeps persistent state and writes segments to disk as it goes — if you close the app, lose your connection, or your computer restarts, the queue restores and downloads continue from where they stopped. Failed tasks retry automatically.

You can limit download speed per video, choose how many worker connections each download uses (1–16), and cap global concurrency at up to 32 simultaneous downloads. Proxy support is included too.

Subtitles

After a download finishes, FetchJAV can transcribe the Japanese audio locally and export .ja.srt, .en.srt, and .zh-TW.srt sidecar files. Everything runs in the background with progress indicators. An optional LLM provider can be configured for higher-quality translations if you want it.

Batch import

Paste plain text, a URL list, or a CSV file. FetchJAV parses the input, validates entries, removes duplicates, resolves metadata, and adds valid items to the queue. Invalid entries are reported without crashing the app. Once a download finishes, the file is saved directly into your Downloads folder.

Queue control

Pause, resume, cancel, retry, and reorder tasks from the queue. Each video shows its own speed, progress, and status, and a persistent history keeps a record of past downloads across restarts.

Play & organize

Preview videos in the built-in player with subtitle selection and resume playback. FetchJAV reads and writes metadata to keep your library tidy automatically, so files stay organized without manual cleanup.

Data & privacy

Your library, queue, and history live in your user profile. Downloading, transcription, and metadata processing all run on your machine — nothing is stored on a FetchJAV server, and no account is required to use the app. FetchJAV has no telemetry and no analytics.

Optional features (such as an LLM provider for translations) only send the specific content you choose to translate, and only when you enable them. The only optional network features are update checks and an LLM endpoint you explicitly configure yourself. By default, FetchJAV is fully offline.

Updates

FetchJAV checks for updates on launch and notifies you when a new version is available. Or you can check for updates manually by going to Settings → Update section.
